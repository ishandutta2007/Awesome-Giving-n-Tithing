## 🔓 Open-Source GitHub Projects

*Repositories are sorted in descending order by GitHub star count. Star count badges link directly to each repository's stargazers.*

1. **[ERPNext (Nonprofit & Giving Modules)](https://github.com/frappe/erpnext)** [![GitHub stars](https://img.shields.io/github/stars/frappe/erpnext?style=social&color=white)](https://github.com/frappe/erpnext/stargazers)  
   Enterprise open-source ERP system featuring a dedicated nonprofit module for donor tracking, recurring pledge accounting, grant management, and tax receipting.

2. **[Liberapay](https://github.com/liberapay/liberapay.com)** [![GitHub stars](https://img.shields.io/github/stars/liberapay/liberapay.com?style=social&color=white)](https://github.com/liberapay/liberapay.com/stargazers)  
   Recurrent donation and patronage platform built on open-source principles with zero platform fee cut, supporting multiple currencies and international payment backends.

3. **[ChurchCRM](https://github.com/ChurchCRM/CRM)** [![GitHub stars](https://img.shields.io/github/stars/ChurchCRM/CRM?style=social&color=white)](https://github.com/ChurchCRM/CRM/stargazers)  
   Mature, self-hosted PHP/MySQL church management system with built-in financial ledger, pledge campaigns, member contribution statements, and deposit management.

4. **[CiviCRM Core](https://github.com/civicrm/civicrm-core)** [![GitHub stars](https://img.shields.io/github/stars/civicrm/civicrm-core?style=social&color=white)](https://github.com/civicrm/civicrm-core/stargazers)  
   Web-based constituent relationship management software designed specifically for nonprofits, NGOs, and faith organizations to process online donations and pledges.

5. **[Rock RMS](https://github.com/SparkDevNetwork/Rock)** [![GitHub stars](https://img.shields.io/github/stars/SparkDevNetwork/Rock?style=social&color=white)](https://github.com/SparkDevNetwork/Rock/stargazers)  
   Extensible relationship management system purpose-built for churches, featuring comprehensive online giving, financial batch processing, text giving, and donor portals.

6. **[B1.church / B1Admin](https://github.com/ChurchApps/B1Admin)** [![GitHub stars](https://img.shields.io/github/stars/ChurchApps/B1Admin?style=social&color=white)](https://github.com/ChurchApps/B1Admin/stargazers)  
   Modern cloud-native and self-hostable church platform providing member directory, attendance, online giving forms, and Stripe integration.

7. **[EcclesiaCRM](https://github.com/phili67/ecclesiacrm)** [![GitHub stars](https://img.shields.io/github/stars/phili67/ecclesiacrm?style=social&color=white)](https://github.com/phili67/ecclesiacrm/stargazers)  
   Modernized fork of ChurchCRM with responsive UI, electronic donation tracking, pledge recordkeeping, and pastoral management tools.

8. **[Lightweight Tithe Tracker](https://github.com/IonicaBizau/tithe)** [![GitHub stars](https://img.shields.io/github/stars/IonicaBizau/tithe?style=social&color=white)](https://github.com/IonicaBizau/tithe/stargazers)  
   Minimalist command-line interface and JavaScript library for tracking, calculating, and logging tithes and charitable contributions.

9. **[True-Tithe & XRPL Experiments](https://github.com/mworks-proj/True-Tithe)** [![GitHub stars](https://img.shields.io/github/stars/mworks-proj/True-Tithe?style=social&color=white)](https://github.com/mworks-proj/True-Tithe/stargazers)  
   Decentralized tithe-tracking experiment utilizing the XRP Ledger (XRPL) for trustless donation verification and crypto-tithe disbursements.

10. **[Church Giving Manager](https://github.com/kmccb/church-giving-manager)** [![GitHub stars](https://img.shields.io/github/stars/kmccb/church-giving-manager?style=social&color=white)](https://github.com/kmccb/church-giving-manager/stargazers)  
    Offline-first desktop software for recording tithes and offerings, organizing envelope giving, and generating annual tax statements without cloud dependencies.

## 🛠️ Frameworks & Architecture for Custom Giving Systems

For organizations desiring complete data ownership without ongoing SaaS subscriptions:
1. **System of Record**: Deploy [ChurchCRM](https://github.com/ChurchCRM/CRM), [Rock RMS](https://github.com/SparkDevNetwork/Rock), or [B1.church](https://github.com/ChurchApps/B1Admin).
2. **Payment Gateway**: Connect a PCI-compliant gateway (e.g., Stripe Elements, PayPal Donation SDK, Paystack, Flutterwave).
3. **Receipts & Statements**: Automate annual PDF giving statements from internal CRM data.
4. **Micro-Churches & Plants**: Pair an offline SQLite tracker with a hosted Stripe payment link to maintain zero monthly overhead.
